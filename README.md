# MAXRENTAL — website mockup

A design mockup for **MAXRENTAL** (MMX Solutions Sdn Bhd), a Malaysian office IT
rental company. Static site, no build step needed to view it — open `index.html`
or browse the published version.

## What's here

11 pages generated by `build.py` from `content.py` and `js/products.js`
(30 real SKUs from their catalogue):

| | |
|---|---|
| `index.html` | Home — 3-slide hero, equipment tabs, journal, reviews |
| `products.html` / `product.html` | Catalogue grid and single-equipment page (`?model=<key>`) |
| `short-term.html` / `long-term.html` | Rental plan tiers |
| `services.html` `about.html` `news.html` `contact.html` | |
| `terms.html` `privacy.html` | |

To regenerate the HTML after editing `content.py`:

```bash
python3 build.py
```

## Status

This is a **mockup, not a finished site.** Known gaps:

- Product imagery is composited from the client's own catalogue cutouts, not
  photography.
- Hero and editorial footage is Pexels stock standing in for a real shoot.
- Authorised-dealer logos are Wikimedia versions, not each vendor's official
  brand assets, and vendor permission has not been confirmed.

Media provenance and the reasoning behind each choice are in
[`CREDITS.md`](CREDITS.md); the analysis of the design reference is in
[`TEARDOWN.md`](TEARDOWN.md).
